# naves-calc

Параметрический МКЭ-стенд для предварительного расчёта металлического автомобильного навеса.

Проект позволяет менять геометрию, сечения, схему опор, нагрузки и стоимость металла, запускать линейный статический расчёт через OpenSeesPy и просматривать результаты в локальном Streamlit-интерфейсе.

> Важно: приложение предназначено для исследовательских и предварительных расчётов. Результаты не являются рабочим проектом, расчётным обоснованием для экспертизы или заменой проверки инженером-конструктором.

## Возможности

- построение параметрической 3D-модели трапециевидного навеса;
- расчёт стержневой модели методом конечных элементов через OpenSeesPy;
- визуализация геометрии, деформированной схемы, усилий, прогибов, реакций и нагрузок;
- проверка осевого использования элементов;
- расчёт массы металла и ориентировочной стоимости;
- сравнение нескольких рассчитанных вариантов;
- экспорт результатов в JSON, CSV, XLSX и HTML-отчёт.

## Геометрия навеса

Навес моделируется как трапециевидный четырёхугольник в плане, а не как прямоугольник.

Координаты контура:

- `A = (0, 0)`
- `B = (12, 0)`
- `C = (12, 7)`
- `D = (0, 10)`

Глубина зависит от координаты `X`:

```text
depth(x) = 10 - 0.25 * x
```

Контрольные значения:

- `depth(0) = 10 м`
- `depth(4) = 9 м`
- `depth(8) = 8 м`
- `depth(12) = 7 м`

Площадь горизонтальной проекции: `102 м²`.

## Установка

Проект рассчитан на запуск через `uv`.

Если `uv` не установлен, установите его:

```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
```

Затем откройте новый терминал и установите зависимости:

```bash
uv sync
```

## Запуск приложения

```bash
uv run streamlit run app.py
```

Если в текущем checkout уже есть настроенное окружение `.venv`, приложение можно запустить без `uv`:

```bash
.venv/bin/streamlit run app.py
```

После запуска Streamlit откроет локальный веб-интерфейс в браузере.

## Запуск тестов

```bash
uv run pytest
```

Некоторые тесты используют `openseespy`. Если пакет недоступен в окружении, соответствующий тест пропускается через `pytest.importorskip`.

## Основные параметры в интерфейсе

В боковой панели Streamlit можно настроить:

- количество нижних и верхних ферм;
- высоту ферм;
- целевую длину панели;
- схему опор;
- сечения поясов, решётки и стоек;
- тип решётки;
- высотные отметки кровли;
- постоянную и снеговую нагрузку;
- коэффициенты снеговой нагрузки;
- стоимость стали, изготовления, стоек, фундаментов и монтажных узлов;
- тип закрепления оснований.

## Пресеты

Базовые варианты находятся в `config/presets.yaml`.

Доступные пресеты:

- `original` — исходная схема с 4 нижними фермами и 10 существующими стойками;
- `naves_one` — отдельная предварительная схема по чертежам «Навес 12×7» для `models/NavesOne.dxf`: 5 ферм серии В, 10 ферм серии Ф и 12 стоек (вариант без `K6`);
- `variant_6x10` — 6 нижних ферм и 10 верхних;
- `variant_4_high` — 4 нижние фермы с увеличенной высотой;
- `variant_6_medium` — 6 нижних ферм средней высоты;
- `variant_7_medium` — 7 нижних ферм средней высоты.

Список доступных профильных труб задаётся в `config/sections.yaml`.

### Модель `NavesOne.dxf`

DXF содержит детализированные поверхности и чертёжные линии, а не готовую стержневую схему. Вариант `naves_one` восстановлен по листам 2–5 и 13–15 PDF «Навес 1809»: контур кровли `(0, 0)–(12, 0)–(12, 7,03)–(2,588, 9,659)` м, нижние фермы В глубиной 500 мм, верхние фермы Ф трапециевидные, 12 стоек 120×120×3. Только F1 имеет высоты 400 → 170 мм. Все F начинаются с 400 мм со стороны K5; перепад высоты каждой фермы равен `230 × L / 12,725` мм, где `L` — её длина в метрах с левым свесом 725 мм. Верхние пояса лежат в общей плоскости кровли, нижние — в другой общей плоскости; уклон поясов одинаков для всех F. По запросу исключена стойка `K6` в точке `(left_x(2,659); 2,659)` м; стойка `K4-middle-2` сохранена; исходный чертёж содержит 13 стоек. Разбиение фермы В1 в месте исключённой опоры сохранено. Пояса ферм заданы трубой 60×60×3, решётка — 40×40×2. Все стойки имеют высоту 2700 мм от общей нулевой отметки (`column_height_mm`). Нижние пояса нижних ферм горизонтальны; плоскость кровли рассчитывается по высоте стоек и ферм. Изменение высот ферм в параметрах меняет отметки кровли, сохраняя высоту стоек. Параметры `lower_height_mm`, `upper_height_mm` и `upper_end_height_mm` заданы в пресете `naves_one`. Ограничение `upper_max_diagonal_mm: 500` автоматически сгущает решётку F, сохраняя узлы опирания: длина каждой диагонали между узлами не превышает 500 мм. Высоты F должны быть меньше этого предела.

Трубы 40×20×1,5 из спецификации (251,31 кг) учитываются как распределённый собственный вес без моделирования их жёсткости. Масса идеализированной схемы составляет около 2798 кг против 2859,49 кг по спецификации за вычетом К6 (исходная спецификация — 2882,91 кг); стержневая идеализация решётки отличается от деталировки чертежа. В текущем МКЭ горизонтальные перемещения всех узлов закреплены, поэтому результаты относятся к вертикальной идеализации, а не к полной пространственной проверке. Расчётные соединения и закрепления оснований на листах не заданы; снеговая и постоянная нагрузки редактируются в интерфейсе.

## Единицы измерения

Внутренняя расчётная система — SI:

- длина: м;
- сила: Н;
- напряжение: Па;
- масса: кг.

Пользовательский интерфейс использует инженерные единицы:

- размеры конструкции: м;
- размеры труб: мм;
- нагрузки: кН/м²;
- силы: кН;
- прогибы: мм;
- масса: кг;
- стоимость: руб.

## Экспорт результатов

После расчёта приложение позволяет выгрузить:

- `naves-calc.json` — исходные данные, сводка и нагрузки;
- `elements.csv` — таблица элементов;
- `results.xlsx` — Excel-отчёт;
- `report.html` — HTML-отчёт.

## Ограничения

- расчёт является предварительным и зависит от корректности заданных параметров;
- проверки не покрывают полный набор требований СП и не заменяют ручную инженерную верификацию;
- снеговая нагрузка и коэффициенты редактируются пользователем;
- модель предназначена для сравнения конструктивных вариантов, а не для выпуска проектной документации.
